# OurTime（iPhone 版）

サーバーを使わず、iPhone の中だけで動く版です。機能は PC 版と同じです。

- データ（予定・病院/お店・薬・写真）は iPhone の Safari の保存領域（IndexedDB）に入ります
- 一度開けばオフラインでも使えます（`sw.js` がキャッシュします）
- 公開するのはこのフォルダの画面ファイルだけです。データは外に出ません

## 公開（GitHub Pages）

このフォルダの中身をそのまま GitHub のリポジトリに置き、Pages を有効にします。
iPhone の Safari で `https://<ユーザー名>.github.io/<リポジトリ名>/` を開き、共有ボタンから「ホーム画面に追加」を選びます。

画面ファイルを更新したときは、`sw.js` の `VERSION` を上げてください（古いキャッシュが消えます）。

## バックアップ

「設定」タブで「バックアップを作成」→「保存先を選ぶ」の順に押し、共有メニューで Google ドライブを選びます。
前回のバックアップから設定した日数（既定: 7日）がたつと、カレンダーの上にお知らせが出ます。

## 復元・PC 版からの移行

「設定」タブの「バックアップファイルを選ぶ」で `.json` を選びます（今のデータはすべて置き換わります）。

PC 版のデータを移すときは、PC の `care-calendar` フォルダで次を実行します。
`G:\マイドライブ\care-calendar-backup\care-iphone-*.json` ができるので、iPhone でそのファイルを選びます。

```bash
npm run export-json
```

## 注意

- ホーム画面からアプリを削除すると、データも消えます
- Safari の「履歴とWebサイトデータを消去」でも消えることがあります
- プライベートブラウズでは使えません
